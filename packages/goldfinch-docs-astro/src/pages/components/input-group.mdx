Joins an input with buttons, addons or a suffix into one control with a shared border.

## Installation

### Barrel

```tsx
import { InputGroup } from "@catiarodrigues/goldfinch";
```

Or as a compound sub-component:

```tsx
import { Input } from "@catiarodrigues/goldfinch";
// Input.Group is available as a sub-component
```

### Granular

```tsx
import { InputGroup } from "@catiarodrigues/goldfinch/components/input-group";
```

Compose it from `InputGroup.Input`, `InputGroup.Button`, `InputGroup.Addon` and `InputGroup.Suffix`. Set `size`, `disabled`, `label` and `error` on the group; its parts inherit them.

<Callout type="info">
  InputGroup picks its focus style from its children: one ring around the whole
  group, or a ring per control when it holds standalone buttons.
</Callout>
