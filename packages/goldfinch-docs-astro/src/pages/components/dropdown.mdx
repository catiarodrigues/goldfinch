A menu of actions or links that opens from a trigger.

## Installation

### Barrel

```tsx
import { DropdownMenu } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { DropdownMenu } from "@catiarodrigues/goldfinch/components/dropdown";
```
