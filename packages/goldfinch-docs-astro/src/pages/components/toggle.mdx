### Group

For several related switches, use:

- `Toggle.Group`, which names the set with a `legend`
- `Toggle.Item`, a labelled switch inside the group
- `Toggle.Legend`, for a custom legend

Items in a group use the `neutral` variant, a softer grey, so no single switch stands out in the list. Set `variant` on the group or on one item to change it.

### When saving fails

A toggle that saves to a server should move as soon as it's clicked and show that it's saving with `transitioning`. If the save fails, move it back to the saved position and explain with `error`. The track stays its usual colour: a red switch would read as a dangerous setting rather than a failed change.
