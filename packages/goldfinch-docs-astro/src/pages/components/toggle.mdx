A switch for a setting that's on or off.

## Installation

### Barrel

```tsx
import { Toggle } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Toggle } from "@catiarodrigues/goldfinch/components/toggle";
```

Control it with `checked` and `onCheckedChange`, or set `defaultChecked` and leave it uncontrolled.

For several related switches, use:

- `Toggle.Group`, which names the set with a `legend`
- `Toggle.Item`, a labelled switch inside the group
- `Toggle.Legend`, for a custom legend

```tsx
<Toggle.Group legend="Preferences">
  <Toggle.Item label="Email notifications" />
  <Toggle.Item label="SMS notifications" />
</Toggle.Group>
```

<Callout type="info">
  Always pair a Toggle with a visible label so users understand what setting it
  controls.
</Callout>
