A dialog that holds focus and blocks the rest of the page until it's closed, for confirmations, short forms or details.

## Installation

### Barrel

```tsx
import { Modal } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Modal } from "@catiarodrigues/goldfinch/components/modal";
```

## Examples

<ComponentExample title="Modal" code={basicCode}>
  <Basic client:visible />
</ComponentExample>

Put `open` and `onOpenChange` on `Modal.Root`, or leave it uncontrolled with a `Modal.Trigger`. Name the dialog with `Modal.Title`. `size` on `Modal` sets the width: `sm`, `base`, `lg` or `xl`.

<Callout type="warning">
  Always include a `Modal.Title`: it gives the dialog its accessible name. Focus
  stays inside the modal while it's open and returns to the trigger when it
  closes.
</Callout>
