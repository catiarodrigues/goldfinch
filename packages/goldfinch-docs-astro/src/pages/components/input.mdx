A text field with built-in support for a label, a description and an error message.

## Installation

### Barrel

```tsx
import { Input } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Input } from "@catiarodrigues/goldfinch/components/input";
```

  <Basic />

`error` shows a message and marks the field invalid. Set `type` for email, password and other input types.

<ComponentExample title="Variants" code={variantsCode}>
  <Variants />
</ComponentExample>

Pass `label`, `description` and `error` straight to Input; it adds the Field around itself. Two related components hang off it:

- `Input.Group` is InputGroup, for an input joined with buttons.
- `Input.Sensitive` is SensitiveInput, which masks its value until revealed.

<Callout type="info">
  Every input needs an accessible name: a `label`, or `aria-label` when there's
  no visible one.
</Callout>
