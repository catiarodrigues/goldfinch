Picks one value from a list. Pass the options as `items`, or write them out as `Select.Option` children for custom markup.

## Installation

### Barrel

```tsx
import { Select } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Select } from "@catiarodrigues/goldfinch/components/select";
```

<ComponentExample title="Items" code={itemsCode}>
  <Items client:visible />
</ComponentExample>

For custom markup, use `Select.Option`, `Select.Group`, `Select.GroupLabel` and `Select.Separator`.

<Callout type="info">
  `items` takes an object map (`{ apple: "Apple" }`) or an array of `{ label, value }`.
</Callout>
