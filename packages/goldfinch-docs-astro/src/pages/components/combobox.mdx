Picks one value from a list by typing to narrow it down. Use it instead of [Select](/components/select) when the list is long enough that people would rather type than scroll, such as countries or time zones.

## Installation

### Barrel

```tsx
import { Combobox } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Combobox } from "@catiarodrigues/goldfinch/components/combobox";
```

Pass `items` as strings, or as `{ value, label }` objects when the value you store differs from the text people see. `value` and `onValueChange` use the value, and `onValueChange` receives `null` when the choice is cleared. `emptyMessage` replaces the list when nothing matches.

### Validation

<ComponentExample title="Error" code={validationCode}>
  <Validation client:visible />
</ComponentExample>

Like the other form controls, `error` marks the input invalid and shows the message below it.

## Keyboard

- Typing filters the list and opens it.
- Arrow keys move through the matches, and Enter chooses one.
- Escape closes the list and keeps focus in the input.
