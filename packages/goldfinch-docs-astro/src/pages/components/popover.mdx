A floating panel anchored to a trigger, for extra actions, filters or details. It closes on Escape or a click outside.

## Installation

### Barrel

```tsx
import { Popover } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Popover } from "@catiarodrigues/goldfinch/components/popover";
```

Compose it from `Popover.Trigger` and `Popover.Content`. It positions itself next to the trigger.

<Callout type="info">
  For a list of actions, use DropdownMenu, which adds menu keyboard navigation.
  For a short label, use Tooltip.
</Callout>
