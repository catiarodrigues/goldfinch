Picks exactly one option from a small set.

## Installation

### Barrel

```tsx
import { Radio } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Radio } from "@catiarodrigues/goldfinch/components/radio";
```

## Examples

<ComponentExample title="Radio" code={basicCode}>
  <Basic client:visible />
</ComponentExample>

Put `Radio.Item`s in a `Radio.Group` with a `legend`. Control the selection with `value` and `onValueChange` on the group, or set `defaultValue` and leave it uncontrolled.

<Callout type="info">
  Tab moves into the group on the selected option, and the arrow keys move the
  selection.
</Callout>
