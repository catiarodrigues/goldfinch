A centred, width-limited wrapper for a page's content, with parts for the title, description and breadcrumbs.

## Installation

### Barrel

```tsx
import { Page } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Page } from "@catiarodrigues/goldfinch/components/page";
```

## Example

<ComponentExample title="Page" code={basicCode}>
  <Basic />
</ComponentExample>

Choose a `size` to control the maximum width: `sm` (48rem), `base` (64rem), `lg` (80rem), or `full` (no constraint).

<Callout type="info">
  Page adds responsive side padding (`px-4`, then `px-6` from `sm` and `px-8`
  from `lg`) so content stays off the edges of the viewport.
</Callout>
