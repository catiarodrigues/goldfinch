Shows where the current page sits in the site's hierarchy, with links back to each parent.

## Installation

### Barrel

```tsx
import { Breadcrumbs } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Breadcrumbs } from "@catiarodrigues/goldfinch/components/breadcrumbs";
```

<Callout type="info">
  Leave `href` off the last item: it then renders as the current page instead of
  a link.
</Callout>
