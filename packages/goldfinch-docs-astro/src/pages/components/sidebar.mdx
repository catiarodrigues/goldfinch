An application sidebar with menus, nested items, collapsible sections and optional resizing.

## Installation

### Barrel

```tsx
import { Sidebar } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Sidebar } from "@catiarodrigues/goldfinch/components/sidebar";
```

## Examples

<ComponentExample title="Sidebar" code={basicCode}>
  <Basic client:visible />
</ComponentExample>

Wrap the layout in `Sidebar.Provider`, which holds the open state and settings such as `collapsible` and `resizable`. Inside `Sidebar`, build the navigation from `Sidebar.Menu`, `Sidebar.MenuItem` and `Sidebar.MenuButton`, and mark the current page with `active`. `Sidebar.Trigger` collapses and expands it.

<Callout type="info">
  Menu buttons take an `icon`, which stays visible when the sidebar collapses to
  icons. Nest items with `Sidebar.MenuSub`.
</Callout>
