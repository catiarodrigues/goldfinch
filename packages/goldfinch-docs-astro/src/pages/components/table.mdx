Displays tabular data with Goldfinch's borders, spacing and type.

## Installation

### Barrel

```tsx
import { Table } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Table } from "@catiarodrigues/goldfinch/components/table";
```

Its parts map to HTML table elements: `Table.Header` is `<thead>`, `Table.Head` is `<th>`, `Table.Body` is `<tbody>`, `Table.Row` is `<tr>` and `Table.Cell` is `<td>`.

<Callout type="info">
  Every part accepts its element's HTML attributes and `className`.
</Callout>
