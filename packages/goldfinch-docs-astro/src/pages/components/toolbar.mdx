A connected horizontal bar of related controls (buttons, inputs and input groups) with `role="toolbar"` and arrow-key navigation.

## Installation

### Barrel

```tsx
import { Toolbar } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Toolbar } from "@catiarodrigues/goldfinch/components/toolbar";
```

## Examples

<ComponentExample title="Toolbar" code={basicCode}>
  <Basic client:visible />
</ComponentExample>

Use `<Toolbar.Button>` for action buttons, `<Toolbar.Input>` for text inputs, and `<Toolbar.InputGroup>` for grouped input+button combos. All toolbar children inherit the toolbar's size and connected styling.

<Callout type="info">
  Tab moves into the toolbar once, and the arrow keys move between its controls.
</Callout>
