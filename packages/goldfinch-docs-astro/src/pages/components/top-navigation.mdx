A top bar for app navigation, with a logo, navigation links and actions on the right. When the bar is narrow, the links move into a Menu button.

## Installation

### Barrel

```tsx
import { TopNavigation } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { TopNavigation } from "@catiarodrigues/goldfinch/components/top-navigation";
```

</ComponentExample>

Give each `TopNavigation.NavItem` an `href`, and mark the current page with `active`, which also sets `aria-current="page"` for screen readers. Links render with the component from `LinkProvider`, so your router's `Link` works here as it does in Sidebar and Breadcrumbs. `TopNavigation.Actions` sits on the right.

### Narrow screens

When the bar is narrower than 42rem, the links collapse into a Menu button that opens them in a panel below the bar. The bar measures its own width, not the window's, so it also collapses inside a narrow column on a wide screen. Escape or choosing a link closes the panel. Resize the window to see it on the example above.
