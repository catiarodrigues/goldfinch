A bar showing how far a task has got, or how much of a limit is used, with a label and a value.

## Installation

### Barrel

```tsx
import { Progress } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Progress } from "@catiarodrigues/goldfinch/components/progress";
```
