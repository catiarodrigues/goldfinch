Adds a label, an optional description and an error message around a form control. Goldfinch's own controls do this through their `label`, `description` and `error` props, so use Field for custom controls.

## Installation

### Barrel

```tsx
import { Field, Input } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Field } from "@catiarodrigues/goldfinch/components/field";
```

Pass the control as children. `error` takes a message, which always shows and marks the field invalid, or `{ message, match }`, which shows only when the browser's validation fails that check.

<Callout type="warning">
  Set `required={false}` to show "(optional)" after the label.
</Callout>
