Lays content out in preset responsive column layouts, from two columns side by side up to six.

## Installation

### Barrel

```tsx
import { Grid, GridItem } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Grid, GridItem } from "@catiarodrigues/goldfinch/components/grid";
```
