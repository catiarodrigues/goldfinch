Switches between related views. There are two styles: `underline`, a classic tab bar, and `segmented`, a pill-shaped control.

## Installation

### Barrel

```tsx
import { Tabs } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Tabs } from "@catiarodrigues/goldfinch/components/tabs";
```

<ComponentExample code={usageCode} />

## Examples

Define the tabs with the `tabs` array. Control the selection with `value` and `onValueChange`, or omit `value` to leave it uncontrolled; it then starts on the first tab.
