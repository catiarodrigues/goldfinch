Hides secondary content behind a trigger, for things like settings panels, FAQ answers or long metadata.

## Installation

### Barrel

```tsx
import { Collapsible } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Collapsible } from "@catiarodrigues/goldfinch/components/collapsible";
```

## Examples

  <Basic client:visible />
</ComponentExample>

Put a trigger and a panel inside `Collapsible.Root`. `Collapsible.DefaultTrigger` and `Collapsible.DefaultPanel` come styled; `Trigger` and `Panel` are unstyled. Control it with `open` and `onOpenChange` on the root.

<Callout type="info">
  The default trigger's caret rotates when the panel opens.
</Callout>
