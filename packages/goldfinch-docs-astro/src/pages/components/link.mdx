Style anchor elements with Goldfinch's link tokens for consistent color, underline, and hover behavior.

## Installation

### Barrel

```tsx
import { Link } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Link } from "@catiarodrigues/goldfinch/components/link";
```

Provide an `href` and children. The component renders an `<a>` tag with Goldfinch typography and color tokens.

<Callout type="info">
  For external links, consider adding `target="_blank"` and `rel="noopener
  noreferrer"` for security.
</Callout>
