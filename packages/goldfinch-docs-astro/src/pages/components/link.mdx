An anchor styled with Goldfinch's link colours, underline and hover state.

## Installation

### Barrel

```tsx
import { Link } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Link } from "@catiarodrigues/goldfinch/components/link";
```

Give it an `href` and content. It renders through `LinkProvider`'s component, an `<a>` by default, so it can use your router's Link.

  For external links, consider adding `target="_blank"` and `rel="noopener
  noreferrer"` for security.
</Callout>
