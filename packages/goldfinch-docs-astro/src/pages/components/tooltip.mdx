A short label for an icon or control. It shows on hover and on keyboard focus.

## Installation

### Barrel

```tsx
import { Tooltip } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Tooltip } from "@catiarodrigues/goldfinch/components/tooltip";
```

## Examples

  <Basic client:visible />
</ComponentExample>

Pass the text as `content` and the trigger as children. A `<Button>` child becomes the trigger itself; anything else is wrapped in a focusable button.

<Callout type="info">
  Touch screens have no hover, so keep essential information out of tooltips.
</Callout>
