Typography for headings, body copy, secondary and monospace text.

## Installation

### Barrel

```tsx
import { Text } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Text } from "@catiarodrigues/goldfinch/components/text";
```

</ComponentExample>

Pick a `variant` for the style and set `as` for the element. TypeScript requires `as` on heading variants, so a heading style always gets a real heading element.

<Callout type="info">
  Without `as`, body variants render a `<p>` and the others a `<span>`.
</Callout>
