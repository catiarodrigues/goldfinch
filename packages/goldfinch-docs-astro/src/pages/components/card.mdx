A container with a border and a light shadow for grouping related content, such as panels and callout blocks.

## Installation

### Barrel

```tsx
import { Card } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Card } from "@catiarodrigues/goldfinch/components/card";
```

Card draws the background, border and shadow. It doesn't add padding, so set your own or use its parts.

For layered layouts, use its parts:

<Callout type="info">
  Card's shadow is light (`shadow-xs`), so cards can sit inside other surfaces.
</Callout>
