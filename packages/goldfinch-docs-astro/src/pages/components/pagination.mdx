Moves through pages of results, with previous and next buttons and a field for jumping to a page number.

## Installation

### Barrel

```tsx
import { Pagination } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Pagination } from "@catiarodrigues/goldfinch/components/pagination";
```
