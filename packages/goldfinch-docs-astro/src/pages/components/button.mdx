Buttons trigger actions. There are five variants and four sizes, plus a loading state and an optional icon.

## Installation

### Barrel

```tsx
import { Button } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Button } from "@catiarodrigues/goldfinch/components/button";
```

| ------------- | --------------------- |
| `secondary`   | Default button style  |
| `primary`     | Main call-to-action   |

| `ghost`       | Subtle, no border     |
| `outline`     | Bordered, transparent |

`shape="square"` makes an icon-only button square.

### Loading

<ComponentExample title="Loading" code={loadingCode}>
  <Loading client:visible />
</ComponentExample>

Set `loading` while an action runs. A spinner takes the icon's place before the label, and the button ignores clicks. It stays focusable, so someone who pressed Enter keeps their place on the page, and `aria-busy` tells screen readers it's working. Change the label too, such as "Save" to "Saving…", so the button says what's happening.

<Callout type="info">
  The label stays visible next to the spinner while loading.
</Callout>
