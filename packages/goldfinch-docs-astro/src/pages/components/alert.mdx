A full-width message bar for release notes, system warnings and validation summaries. It can show an icon, a title, a description and an action.

## Installation

### Barrel

```tsx
import { Alert } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Alert } from "@catiarodrigues/goldfinch/components/alert";
```
