Fills the space when a list or search has nothing to show, saying why it's empty and what to do next.

## Installation

### Barrel

```tsx
import { EmptyState } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { EmptyState } from "@catiarodrigues/goldfinch/components/empty-state";
```
