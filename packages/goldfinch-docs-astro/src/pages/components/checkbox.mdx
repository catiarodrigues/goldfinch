Turns a single option on or off. It also has an indeterminate state for a parent whose options are partly selected.

## Installation

### Barrel

```tsx
import { Checkbox } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Checkbox } from "@catiarodrigues/goldfinch/components/checkbox";
```

## Examples

  <Basic client:visible />
</ComponentExample>

Control it with `checked` and `onCheckedChange`. Without `checked` it manages its own state and starts unchecked. For a set of options, use `Checkbox.Group`.

<Callout type="info">
  `indeterminate` only changes how the box looks. Set it yourself from the state
  of the options it summarises.
</Callout>
