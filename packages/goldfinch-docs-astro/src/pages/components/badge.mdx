A small label for status, categories or metadata.

## Installation

### Barrel

```tsx
import { Badge } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { Badge } from "@catiarodrigues/goldfinch/components/badge";
```

### Dot badges

`appearance="dot"` adds a coloured status dot. It works with the `success`, `warning`, `error` and `neutral` variants.

<ComponentExample title="Dot badges" code={dotCode}>
  <Dot />
</ComponentExample>

### In a sentence

Badges sit inline with text, so they can label an item where it's mentioned.

<ComponentExample title="In a sentence" code={inSentenceCode}>
  <InSentence />
</ComponentExample>

### Sizes

There are three sizes: `sm` for tight inline use, `md` (the default) and `lg` for a badge that stands on its own.
