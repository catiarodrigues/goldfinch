Short notifications that appear in the bottom-right corner and dismiss themselves after a few seconds.

## Installation

### Barrel

```tsx
import { Toast, createGoldfinchToastManager } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import {
  Toast,
  createGoldfinchToastManager,
} from "@catiarodrigues/goldfinch/components/toast";
```

## Examples

</ComponentExample>

Wrap your app in `Toasty`, then call `useGoldfinchToastManager()` inside it and `toast.add({ title, description })`. To show toasts from outside React, create a manager with `createGoldfinchToastManager()` and pass it to `Toasty` as `toastManager`.

<Callout type="warning">Render one `Toasty` near the root of your app.</Callout>
