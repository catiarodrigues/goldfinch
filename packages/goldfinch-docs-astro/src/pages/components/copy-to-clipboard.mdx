Shows a read-only value with a button that copies it, for things like API tokens, install commands and IDs.

## Installation

### Barrel

```tsx
import { CopyToClipboard } from "@catiarodrigues/goldfinch";
```

### Granular

```tsx
import { CopyToClipboard } from "@catiarodrigues/goldfinch/components/copy-to-clipboard";
```

`text` is what's shown and copied. Set `textToCopy` when the copied value should differ from what's shown, such as a full token behind a shortened one.

<Callout type="info">
  Browsers only allow the Clipboard API on HTTPS and localhost. Elsewhere the
  component falls back to the older copy command.
</Callout>
