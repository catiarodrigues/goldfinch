## Prerequisites

Goldfinch requires **React 19** and **Tailwind CSS v4** in your project.

## Install

```bash
npm install @catiarodrigues/goldfinch
```

Or using pnpm:

```bash
pnpm add @catiarodrigues/goldfinch
```

## Set up Tailwind CSS v4

Goldfinch's stylesheet ships as Tailwind source, so your Tailwind build generates the classes
its components use. If your project doesn't use Tailwind v4 yet, install it:

```bash
npm install -D tailwindcss @tailwindcss/vite
```

Add the Vite plugin:

```ts
// vite.config.ts
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
import tailwindcss from "@tailwindcss/vite";

export default defineConfig({
  plugins: [react(), tailwindcss()],
});
```

## Add the styles

In your main CSS file (e.g. `src/index.css`, imported once from your app entry):

```css
@import "@catiarodrigues/goldfinch/styles";
@source "../node_modules/@catiarodrigues/goldfinch/dist";
```

<Callout type="info">
  `@source` is required — Tailwind v4 doesn't scan `node_modules`, so without it the components
  render unstyled. The path is relative to your CSS file. The Goldfinch stylesheet already
  includes `@import "tailwindcss"`, so don't add a second one.
</Callout>

## Use a component

```tsx
import { Button } from "@catiarodrigues/goldfinch";

export default function App() {
  return <Button variant="primary">Click me</Button>;
}
```

<Callout type="info">
  Goldfinch components are tree-shakeable. Import exactly what you need — unused components are dropped by your bundler.
</Callout>
