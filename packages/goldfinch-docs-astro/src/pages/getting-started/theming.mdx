Every colour Goldfinch uses is a CSS custom property, so you can theme it by overriding them.

## How it works

The library defines tokens at three levels:

1. `@theme` registers the tokens with Tailwind, which creates utilities such as `bg-goldfinch-base`.
2. `:root` sets the light-mode values.
3. `[data-mode="dark"]` sets the dark-mode values.

## Override a token

To customize a color, redeclare the variable with higher specificity:

```css
:root {
  --color-goldfinch-brand: #2563eb;
  --color-goldfinch-brand-hover: #1d4ed8;
}
```

## Token reference

Every token, with its light and dark value, is listed on the [Colors](/getting-started/colors) page. Token names follow the pattern `--{category}-goldfinch-{name}`.

<Callout type="info">
  Set `data-mode="dark"` on `<html>` to switch to dark mode. Without it, Goldfinch uses the light values.
</Callout>
